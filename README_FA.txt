سامانه آنلاین تولید نامه PDF — نسخه HTML + سرور

این نسخه یک فرم HTML واقعی است. کاربر فقط لینک سایت را باز می‌کند؛ هیچ Python یا کتابخانه‌ای روی دستگاه کاربر لازم نیست.
تولید PDF در سرور انجام می‌شود و فایل Word اصلی مبنای خروجی است.

آزمایش روی رایانه توسعه‌دهنده:
1) Python فقط برای اجرای سرور محلی لازم است؛ کاربر نهایی به آن نیاز ندارد.
2) LibreOffice را نصب کنید.
3) در پوشه پروژه اجرا کنید:
   pip install -r requirements.txt
   python app.py
4) در مرورگر باز کنید:
   http://127.0.0.1:5000

انتشار اینترنتی:
- روش پیشنهادی: استقرار با Docker روی هر میزبان دارای پشتیبانی Docker.
- Dockerfile از قبل نصب LibreOffice و فونت را در کانتینر انجام می‌دهد.
- پورت برنامه 8080 است و باید پشت HTTPS/reverse proxy یا سرویس میزبانی مناسب قرار بگیرد.
- پس از استقرار، نشانی عمومی میزبان را در گروه منتشر کنید.

حریم خصوصی:
- هیچ دیتابیسی وجود ندارد.
- اطلاعات فقط برای تولید فایل در حافظه درخواست استفاده می‌شوند.
- فایل‌های موقت در پایان هر درخواست پاک می‌شوند.
- برای میزبانی واقعی، لاگ‌های سرور را از ثبت body درخواست و اطلاعات فرم محافظت کنید و سیاست نگهداری لاگ میزبان را بررسی کنید.

اعتبارسنجی:
- سمت مرورگر حداکثر ۱۰ رقم پذیرفته می‌شود.
- دکمه تولید تا ورود دقیقاً ۱۰ رقم و نام فعال نمی‌شود.
- سرور نیز مستقل از مرورگر اعتبارسنجی را تکرار می‌کند.
